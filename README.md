# IT Operations Engineering

Repositorio profesional de soluciones verificadas para operaciones de TI, con prácticas reproducibles de Git, Linux, redes y automatización.

## Propósito

Documentar la resolución técnica de incidencias de laboratorio mediante diagnósticos sustentados, configuraciones controladas, pruebas ejecutables y procedimientos operativos claros.

Los casos incluidos son escenarios ficticios de laboratorio. No contienen datos ni resultados procedentes de sistemas empresariales reales.

## Criterios de publicación

Una solución se incorpora cuando:

- reproduce y documenta el problema;
- identifica la causa mediante evidencias;
- aplica un cambio mínimo y revisable;
- supera pruebas reproducibles;
- incluye un procedimiento de reversión cuando corresponde;
- no contiene secretos, datos personales ni material de formación privada.

## Estructura

- `incidents/`: incidencias resueltas y verificadas.
- `configs/`: configuraciones de ejemplo saneadas.
- `scripts/`: automatizaciones operativas.
- `tests/`: pruebas reproducibles.
- `runbooks/`: procedimientos de operación y recuperación.
- `docs/`: documentación técnica complementaria.

## Estado

Estructura inicial preparada. Las soluciones se añadirán progresivamente después de superar sus criterios de aceptación.
